## Stage 1 — international source discovery (initial reachability complete; ongoing quality monitoring)

Build a read-only source matrix and probe the sources from the actual GitHub Actions runtime:

1. **Binance Spot public market data** — already integrated as the primary external OHLCV research source and market-structure input. Keep this lane unauthenticated and Spot-only.
2. **Kraken Spot public REST/WebSocket** — already integrated as the independent OHLC, trade and order-book cross-check. Keep quote currencies distinct; do not infer USD/USDT conversions.
3. **Tabdeal local Spot** — remains the only execution venue and the only source of executable local quotes, order-book depth, pair rules and eventual order eligibility. The IRT unit and book sequence/snapshot semantics are still unresolved.
4. **Alternative.me Fear & Greed** — the only new auxiliary source cleared for recurring context collection. PR #20 is merged; initial push-triggered history capture succeeded with 3,217 daily records. Daily schedule delivery still needs to be independently observed. Use only as BTC-focused context, with attribution and a full 24-hour historical lag; never as a stand-alone entry signal.
5. **CoinGecko Demo / CoinMarketCap Basic / FRED** — optional later sources requiring registered API keys. Do not add them without a measured coverage gap and a separate key/terms review.
6. **Bitycle Cap Business API** — a promising vendor lead for Iranian-exchange metadata and OHLCV, including Toman pairs; API-key access is required and pricing, Tabdeal coverage and data-retention rights remain unverified. Request a free sandbox/quote before any integration.
7. **Social/Telegram sources** — named channels are human-review leads only. Do not scrape, bulk collect or archive Telegram messages for AI/ML research absent Telegram-required permissions/consents. Only consider direct provider-authorized feeds/exports with explicit rights. See [Social signal discovery policy](SOCIAL-SIGNAL-DISCOVERY.md).
8. **Coin Metrics Community and DefiLlama** — one-off response-shape probes passed, but their current terms do not clear this automated trading-research use. Exclude from recurring workflows and model features unless written rights are secured. See [Auxiliary data sources](AUXILIARY-DATA-SOURCES.md).

For each provider, record official documentation, terms, rate limits, authentication requirements, symbol coverage, quote currency, timestamp units, historical depth, pagination, data freshness, GitHub Actions reachability, failure modes and fallback behaviour. The core discovery path uses no-key Binance Spot Market Data Only and Kraken public Spot market-data endpoints. CoinGecko is optional; its current free Demo access requires a Demo API key, so defer it unless a concrete research need justifies it. No paid API, account, transfer or private exchange secret is required for the initial path. Network reachability must be demonstrated in the real workflow runtime; do not assume that browser access or local access proves runner access.

## Stage 2 — normalize and cross-check against Tabdeal (partially complete)

Persist timestamped source observations with immutable provenance and explicit units. Validate candle close times, OHLCV invariants, gaps, duplicates, out-of-order rows, pagination completeness, reconnect behaviour and source freshness. Never fill missing bars merely to make a continuous chart.

Map only the same underlying asset and quote currency when comparing venues. Keep USDT, USD, IRT, RIAL and TOMAN distinct. Where quote currencies differ, require a separately verified conversion/reference and measure the local basis; otherwise mark the comparison unusable. Use external feeds to discover candidates, then confirm the candidate on Tabdeal with a fresh local Spot book, spread, depth, fees, minimum notional/lot size and verified price units. An external price must never be passed to the Tabdeal executor as if it were local.

Continue collecting Tabdeal public Spot order-book observations for local validation. Current depth-stream diagnostics remain provisional until Tabdeal confirms snapshot/delta and sequence semantics. The currently tested Binance-style Spot @trade/@aggTrade topic names were rejected; do not guess undocumented Tabdeal topics or substitute a leveraged/FAPI stream.

## Stage 3 — pre-registered strategy research (original 135-hypothesis intraday screen completed; daily profile now registered)

Evaluate deterministic hypotheses on sufficiently complete, timestamp-aligned multi-source history. Compare against simple trend/momentum and matched naive baselines. Use chronological train/validation/untouched holdout splits, walk-forward evaluation, multiple-testing correction, and realistic fees, spread, slippage, latency, partial fills and liquidity constraints. The new `1d` profile uses 250 train bars, 30-bar non-overlapping tests, 60 OOS windows and a global Benjamini-Hochberg correction across all four horizons. It is not eligible until each series has at least 2,563 closed daily bars; insufficient history must remain unavailable rather than reduce the sample floor. Order Block/SMC concepts remain optional unproven hypotheses; they are not a predetermined strategy or a reason to relax evidence requirements.

## Stage 4 — forward paper trading (lean MVP; experimental only, not live-authorized)

Only promote independently validated candidates. Run a continuous forward Paper ledger using Tabdeal-local prices and order-book evidence, with restart/reconciliation, stale-data, duplicate-order, daily-loss, drawdown and kill-switch tests. Report net return, drawdown, trade count, exposure, costs and comparison to suitable benchmarks. A no-trade result is valid.

## Stage 5 — capped live pilot (adapter foundation in this public PR; not deployed, enabled or authorized)

Requires all data and strategy gates to pass, written verification of Tabdeal account/API permissions and terms, a separately audited fail-closed execution adapter, independent reconciliation, hard risk limits and explicit owner approval. No live order path is present in this public repository. Never enable leverage, shorting, margin, transfers or withdrawals as part of this Spot project.
